# K-Storm 评委 5 分钟介绍

> 本地多 Agent 科研选题头脑风暴工作台。10 个专职 Agent 协同完成从输入整合到最终报告的全流程。

## 一句话定位

**把"问一次 AI"升级为"可复盘、可追溯、可批判的多 Agent 科研决策链"。**

## 核心差异化（3 个卖点）

### 1. 多角色分工 + 冲突显式化
- 4 个讨论 Agent（创新/机制/可行性/审稿）+ Moderator 汇总冲突点与遗漏点
- 不是让模型自圆其说，而是把分歧暴露出来，生成下一轮问题清单

### 2. 结构化 IR + 证据绑定 + 在线核验
- 候选方向绑定 evidence_refs（来自模板/文档/讨论）+ critique_refs
- 引用可对 arXiv/Crossref/OpenReview 在线核验，标注「已核验/不一致/未找到」
- 产出可复盘，而非一段话

### 3. 独立批判 + 人工介入
- Critique Agent 在讨论结束后独立做六维风险评估（创新性/证据链/可行性/一致性/偏见/下一步）
- 用户可在每轮后插入意见，下一轮 Agent 自动携带并回应

## 演示路径（3 分钟）

1. **一键演示案例**（断网可用，90 秒）
   - 新建讨论 → 「⚡ 一键演示：LLM 安全诊断」
   - 展示 3 轮讨论链 → Critique 批判 → 最终报告 → 28 条引用（含在线核验徽章）

2. **真实模型演示**（需网络+Key，60 秒，可选）
   - 模型设置 → 107 平台 → ⚡一键配置
   - 参赛演示模式填模板 → 启动讨论，展示流式逐字输出

## 技术栈

React 19 + FastAPI + SQLite(WAL)，自研状态机编排，59 个后端测试。完全本地运行，零云端依赖。

## 对比直接问 LLM

见 [README.md#🆚-k-storm-vs-直接问-llm](../README.md)。核心：单一模型单次回答 → 多角色结构化决策链，产出可复盘可追溯。

## 能力边界（诚实声明）

- 引用核验基于公开 API（arXiv/Crossref），非论文全文数据库；未覆盖的标「待人工核实」
- 记忆检索为 TF-IDF + LLM 查询扩展，非语义向量库
- 桌面封装为后续阶段，当前为前后端参赛版
